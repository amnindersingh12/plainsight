unseen

See the text that humans can't, but AI agents can.

GitHub: CLI, Action, pre-commit

Runs entirely in your browser. Nothing you paste leaves this page.

1. Paste text

Treat as

Code mode fails on bidi controls and invisible fillers. Prose mode only warns on them, because Arabic, Hebrew and braille text use them legitimately. Strict turns every warning into a failure.

2. What it really contains

Hide a message (test your own agents)

Encodes ASCII as invisible Unicode tag characters after a normal-looking cover text. Paste the result into your AI tool and see whether it obeys.

The same rules as the command-line tool (Unicode ). Block it in CI:

pipx install "git+https://github.com/amnindersingh12/plainsight#subdirectory=unseen"
unseen scan .
